Adding JavaScript to HTML

Complete Study Notes & Reference

JavaScript can be added to an HTML document in three main ways:

1. Internal JavaScript (Embedded JavaScript)

Definition

Internal JavaScript is written directly inside the HTML file between the <script> and </script> tags. The browser treats everything inside these tags as executable script rather than standard HTML code.

Syntax

<script>
    // JavaScript code goes here
</script>

Example

<!DOCTYPE HTML>
<html>
<head>
    <title>Internal JS Example</title>
</head>
<body>
    <script>
        var greet = "Hello World!";
        document.write(greet);
    </script>
</body>
</html>

Key Points

  • Location: Placed inside the <head> or <body> section of an HTML document.
  • Best Used For: Small scripts or single-page applications.
  • Limitation: Cannot be reused across multiple HTML pages.

2. External JavaScript

Definition

External JavaScript involves writing the script in a separate file with a .js extension and linking it to the HTML document using the src attribute of the <script> tag.

Syntax

<script src="filename.js"></script>

Example

External file (hello.js):

function sayHello() {
    alert("Hello Nepal!");
}

HTML File (index.html):

<!DOCTYPE HTML>
<html>
<head>
    <title>External JS Demo</title>
    <script src="hello.js"></script>
</head>
<body>
    <input type="button" onclick="sayHello()" value="Click Me">
</body>
</html>

Key Points

  • File Extension: Saves code separately in a file ending with .js (contains no HTML tags).
  • Advantages:
    • Reusability: The same .js file can be linked to multiple HTML pages.
    • Code Cleanliness: Keeps HTML and JavaScript separate, making code easier to read and maintain.
    • Faster Loading: Browsers can cache external JavaScript files to speed up page load times.

3. Inline JavaScript

Definition

Inline JavaScript is written directly inside an HTML tag attribute using event handlers (such as onclick, onmouseover, onload, onkeypress, etc.).

Syntax

<tagname event_attribute="JavaScript code">

Example

<!DOCTYPE HTML>
<html>
<head>
    <title>Inline JavaScript</title>
</head>
<body>
    <button onclick="alert('Hello World!')">Click Me</button>
</body>
</html>

Key Points

  • Trigger: Code executes only when the specific event (like a button click) is triggered by the user.
  • Common Event Attributes: onclick, onmouseover, onkeypress, onload.
  • Disadvantage: Clutters HTML markup with script logic, making long programs difficult to read and maintain.

Quick Comparison Table

Feature Internal JS External JS Inline JS
Location Inside <script> tags in HTML In a separate .js file Inside an HTML tag's event attribute
