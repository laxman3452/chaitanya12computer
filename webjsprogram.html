Part 1: Basic Logic & Conditions

Qn(1). Write a javascript code to find greatest number among 3 number entered by the user.
let a = Number(prompt("Enter first number:"));
let b = Number(prompt("Enter second number:"));
let c = Number(prompt("Enter third number:"));

if (a >= b && a >= c) {
    document.write("Greatest number is: " + a);
}
else if (b >= a && b >= c) {
    document.write("Greatest number is: " + b);
}
else {
    document.write("Greatest number is: " + c);
}

Part 2: HTML & JavaScript Programs

Qn 1. Write a javascript code along with html that displays the multiplication table of a entered number.
<html>
<head>
    <title>Multiplication Table</title>
</head>
<body>

<script>
var n = prompt("Enter a number:");

document.write("<h2>Multiplication Table of " + n + "</h2>");
var i = 1;
while (i <= 10) {
    document.write(n + " × " + i + " = " + (n * i) + "<br>");
    i++;
}
</script>

</body>
</html>

Qn 3. How do you add event handler in js? Give example.
An event handler is a JavaScript code or function that runs when a specific event happens on a webpage.
Demonstration of onclick event handler:

<html>
<body>

<button onclick="showMessage()">Click Me</button>

<script>
function showMessage() {
    alert("Button was clicked!");
}
</script>

</body>
</html>


Demonstration of onSubmit event handler:

<html>
<body>

<form onsubmit="showMessage()">
    Enter your name:
    <input type="text">
    <input type="submit" value="Submit">
</form>

<script>
function showMessage() {
    alert("Form submitted!");
}
</script>

</body>
</html>

Qn 5. Write a Program in javascript that finds factorial of a given number.
<!DOCTYPE html>
<html>
<head>
    <title>Factorial</title>
</head>
<body>

<script>
    function factorial() {
        var n = Number(prompt("Enter a number:"));
        var fact = 1;
        var i = 1;

        while (i <= n) {
            fact = fact * i;
            i++;
        }

        document.write("Factorial = " + fact);
    }

    factorial();
</script>

</body>
</html>
